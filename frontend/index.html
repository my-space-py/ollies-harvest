공지

올리의 수확 사용법

필독 처음 오셨나요? 올리의 수확 한눈에 보기

🌾 1. 쌀 모으기

  • 가운데 올리를 클릭하면 쌀알을 수확해요. (1쌀알 = 실제 쌀 1g)
  • 가만히 있어도 초당 수확량만큼 자동으로 쌓여요. 게임을 꺼 둔 동안에도 최대 24시간까지 모아 둬요.

⬆ 2. 장비 강화 (업그레이드 탭)

  • 내부 강화: 쌀알로 지금 장비를 한 단계씩 강화해요.
  • 다음 티어: 게임 LV이 오르면 더 좋은 장비로 바꿀 수 있어요. 수확량이 크게 늘어나요.

🍚 3. 쌀 소비하기 = 성장하기 (쌀 소비 탭)

  • 이 게임의 핵심은 쌀을 소비하는 거예요. 쌀을 쓰면 누적 쌀 소비량이 올라가고, 소비량에 따라 게임 LV이 올라가요.
  • 레시피 11종은 소비량이 늘수록 하나씩 열려요. ×1 / ×10 / ×100 / MAX로 한 번에 여러 개 만들 수 있어요.
  • 밥 → 다음 비료 시간 증가 · 김밥 → 클릭 ×3 · 떡 → 자동 ×3 · 쌀빵 → 다음 비료 배율 증가 · 누룽지 → 전체 ×2
  • 주먹밥 → 클릭 대박(10% 확률 ×10) · 식혜 → 쉬는 동안 수확 증가 · 쌀과자 → 소비량 1.5배 인정 · 떡국 → 다음 LV 보상 2배 · 비빔밥 → 켜진 효과 시간 연장 · 쌀국수 → 비료 획득(하루 5개)
  • 잔치: 한 번에 많은 쌀을 써서 영구 보너스를 받아요. 동네 밥상부터 순서대로 열려요.
  • 쌀 기부: 보유 쌀알의 일부를 이웃에게 나눠요. 기부한 쌀도 소비량이 되고, 모이면 배지를 받아요.
  • 주문 배달: 손님 주문을 제한 시간 안에 납품하면 쓴 쌀의 1.5배를 대금으로 받아요.

🌱 4. 비료 부스터

  • 하단 비료 사용 버튼을 누르면 일정 시간 전체 수확량이 2배가 돼요.
  • 켜져 있을 때 또 쓰면 시간이 늘어나요. 단, 남은 시간은 최대 30분을 넘을 수 없어요.
  • 비료는 LV업, 오늘의 미션, 출석, 소비 마일스톤 보상으로 얻어요.

🎁 5. 보상 챙기기

  • 오늘의 미션: 매일 자정에 초기화되는 4가지 과제
  • 출석: 접속한 날마다 한 칸씩, 7일 동안 보상
  • 이벤트: 바로 할 수 있는 깜짝 과제. 달성하면 보유 쌀알이 1.5배!
  • 통계 탭의 소비 마일스톤도 소비량을 채우면 자동으로 보상이 지급돼요.

🏆 6. 친구와 랭킹

  • 친구 탭에서 내 친구 코드를 알려주거나, 친구 코드를 입력해 친구를 맺어요.
  • 랭킹 탭은 이번 주(월요일 시작) 누적 수확량 순위예요.

💾 7. 저장

  • 진행 상황은 자동으로 저장되고 계정에 연결돼요. 다른 기기에서 로그인해도 이어서 할 수 있어요.
  • 우측 상단 초기화는 모든 진행이 지워지니 조심하세요!
