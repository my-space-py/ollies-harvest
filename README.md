# 올리의 수확

> 쌀을 수확하고, 맛있게 소비하며 작은 쌀 축제를 완성하는 HTML5 방치형 게임

`올리의 수확`은 **쌀 사용량 촉진**을 주제로 제작 중인 웹 기반 방치형 게임입니다.
플레이어는 올리와 함께 쌀을 수확하고, 모은 쌀로 다양한 음식을 만들며 쌀 소비의 즐거움과 가치를 경험합니다.

이 게임에서 쌀 소비는 단순한 비용이 아닙니다. 쌀을 소비할수록 인기도와 경험치가 오르고, 새로운 레시피와 성장 콘텐츠가 열립니다.

## 게임 목표

MVP의 최종 목표는 다음 조건을 달성해 **작은 쌀 축제**를 개최하는 것입니다.

- 누적 쌀 소비량 `30kg` 달성
- 인기도 `100` 달성
- 레시피 `5종` 해금

추후에는 누적 쌀 소비량 `100kg`을 달성해 지역 대표 쌀 축제를 개최하는 확장 콘텐츠를 추가할 예정입니다.

## 핵심 플레이

```text
쌀 수확
  -> 생산 업그레이드
  -> 레시피로 쌀 소비
  -> 누적 소비량과 인기도 증가
  -> 새로운 레시피와 보상 해금
  -> 더 많은 쌀을 수확하고 소비
  -> 작은 쌀 축제 개최
```

게임 내 `1 쌀알`은 실제 쌀 `1g`을 의미합니다. 보유량보다 **누적 쌀 소비량**을 핵심 점수로 삼아 공모전 주제를 플레이 과정에 직접 연결합니다.

## 주요 기능

- 올리를 클릭해 쌀을 얻는 클릭 수확
- 기본 `15g/s` 자동 수확과 생산 업그레이드
- 최대 4시간까지 반영되는 오프라인 수확 보상
- 밥, 김밥, 떡, 쌀빵, 누룽지 레시피
- 레시피 소비에 따른 인기도, 경험치, 생산 버프
- 생산, 클릭, 소비 효율 업그레이드 6종
- 초반 플레이 흐름을 안내하는 미션 5종
- 누적 쌀 소비량 마일스톤
- 작은 쌀 축제 개최 목표
- 브라우저 `localStorage` 기반 자동 저장
- 모바일 및 데스크톱 반응형 화면

## MVP 레시피

| 레시피 | 쌀 소비량 | 주요 보상 |
| --- | ---: | --- |
| 밥 짓기 | 150g | 인기도와 경험치 획득 |
| 김밥 만들기 | 120g | 30초간 클릭 수확 +50% |
| 떡 만들기 | 250g | 30초간 자동 수확 +50% |
| 쌀빵 굽기 | 300g | 높은 인기도와 경험치 획득 |
| 누룽지 만들기 | 200g | 영구 자동 수확 효율 증가 |

## 기술 구성

- HTML5
- CSS3 반응형 레이아웃
- Vanilla JavaScript
- Web Storage API (`localStorage`)

별도의 프레임워크나 빌드 과정 없이 정적 웹 환경에서 실행할 수 있습니다.

## 로컬 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python3 -m http.server 4174
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:4174
```

## 협업 방식

안정적으로 실행 가능한 코드는 `main` 브랜치에서 관리합니다. 새로운 기능은 별도 브랜치에서 작업한 뒤 Pull Request를 통해 병합합니다.

권장 브랜치 이름:

```text
feature/recipe-system
feature/game-balance
feature/ui-polish
fix/save-data
asset/ollie-animation
```

권장 작업 순서:

1. GitHub Issue에 작업 목적과 완료 조건을 작성합니다.
2. Issue 기준으로 기능 브랜치를 생성합니다.
3. 한 커밋에는 하나의 명확한 변경 목적을 담습니다.
4. Pull Request에서 실행 화면과 테스트 내용을 공유합니다.
5. 리뷰가 끝난 코드를 `main`에 병합합니다.

PNG 같은 이미지 파일은 자동 병합이 어렵기 때문에 하나의 파일을 여러 사람이 동시에 수정하지 않습니다. 교체 전 이미지는 즉시 덮어쓰지 않고 버전을 구분해 관리합니다.

## 기획 문서

게임의 상세 목표, 밸런스, 레시피 보상, 성장 단계와 MVP 범위는 [GAME_DESIGN.md](./GAME_DESIGN.md)에서 확인할 수 있습니다.

기획 변경이 게임 규칙이나 목표 수치에 영향을 준다면 코드보다 먼저 기획 문서를 갱신합니다.

## 배포

이 프로젝트는 정적 웹 게임이므로 GitHub Pages로 배포할 수 있습니다.

저장소의 `Settings > Pages`에서 배포 소스를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/(root)`로 지정하면 됩니다.

배포 주소는 다음 형식으로 생성됩니다.

```text
https://GITHUB_ID.github.io/REPOSITORY_NAME/
```

## 저장 데이터 안내

게임 진행 상황은 이용자의 브라우저에 저장됩니다. 브라우저 데이터가 삭제되거나 다른 기기 또는 브라우저로 접속하면 기존 진행 상황이 공유되지 않습니다.

온라인 계정, 공용 랭킹, 기기 간 저장 연동은 별도의 서버 기능이 필요한 확장 범위입니다.

## 현재 상태

공모전 출품을 위한 프로토타입을 개발 중입니다. 현재 핵심 수확, 소비, 성장, 미션, 저장 루프가 구현되어 있으며, 앞으로 아트 에셋 보강, 연출 개선, 초반 밸런스 조정과 사용성 테스트를 진행합니다.
